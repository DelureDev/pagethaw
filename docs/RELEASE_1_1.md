# PageThaw 1.1 — normal Word editing

Choose **Editable text** to get ordinary Word paragraphs and expanding cells for
form blanks. Body text has no floating text boxes. Adding text moves the following
content; field labels and captions stay with their blanks across page breaks.

**Preserve layout** remains available for the original positioned-text output.
Both modes appear in the English/Russian interface. Font checks, explicit
replacement approval, offline processing and DOCX-only output folders remain.

Download the single Windows EXE below; no installation is needed. The ZIP is an
optional folder edition. No new runtime dependencies were added.

Editable mode supports simple single-column digital forms. Spacing and page count
can change. Complex grids, columns and overlapping graphics are rejected with a
reason. Footnotes and list numbers remain ordinary text. Fonts are not embedded:
recipients need the same fonts installed. Review every converted document.

Validation: 97 automated tests; 14 supported documents / 27 rendered pages checked
independently; three representative forms tested after long entries, added text
and paragraph deletion. Another 21 corpus files were explicitly unsupported in
editable mode. This is a bounded capability, not universal PDF reconstruction.

## Русский

Добавлен режим **Редактировать текст**: обычные абзацы Word и поля в ячейках
таблиц, без плавающих текстовых блоков. При добавлении текста содержимое ниже
сдвигается. Подписи к полям остаются рядом с ними при переносе на другую страницу.

Прежний режим **Сохранить макет** тоже доступен. Выбор шрифтов, работа без
интернета и папка результата только с файлами DOCX сохранены.

Новый режим рассчитан на простые бланки в одну колонку. Интервалы и число страниц
могут измениться. Сложные таблицы и колонки пока не поддерживаются; сноски и номера
списков остаются обычным текстом. Шрифты у получателя должны быть установлены.
Проверяйте результат перед использованием.
